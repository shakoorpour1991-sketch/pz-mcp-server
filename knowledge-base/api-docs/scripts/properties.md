# Properties

Soft Override  
Unknown

Define stat changes applied to the player drinking this
[fluid](https://pz-wiki-modding.github.io/PZ-API-Docs/scripts/fluid.html)
or properties for a
[tile](https://pz-wiki-modding.github.io/PZ-API-Docs/scripts/tile.html).

## Hierarchy

This block can be a child of the following blocks:

- [fluid](./fluid.md)
- [tile](./tile.md)

## ID

This block should have no ID.

## Parameters

#### alcohol

Type  
float

No description provided.

#### Calories

Type  
float

The number of calories this fluid provides when consumed.

#### Carbohydrates

Type  
float

The amount of carbohydrates this fluid provides when consumed.

#### enduranceChange

Type  
float

The amount of endurance given back.

#### fatigueChange

Type  
float

The amount of fatigue this fluid changes when consumed. Positive values
increase fatigue, negative values decrease it.

#### fluReduction

Type  
float

No description provided.

#### foodSicknessChange

Type  
float

The amount of food sickness provides.

#### HungerChange

Type  
float

The amount of hunger this fluid changes when consumed. Positive values
increase hunger, negative values decrease it.

#### Lipids

Type

The amount of pain this fluid reduces when consumed.
