# ROOT-TMXconfig

Soft Override  
Unknown

Is Root  
True

No comma  
True

Root patterns  
`TMXconfig\.txt$`

The `TMXconfig.txt` file is used to configure the default layers which
will be created in the TMX file.

## Hierarchy

This block can have the following child blocks:

- [layers](../layers.md)

## ID

This block should have no ID.

## Parameters

#### revision

Type  
integer

Revision of the TMXconfig file. Keep it to 11 for now.

#### version

Type  
integer

Version of the TMXconfig file. Should be 1 for now.
