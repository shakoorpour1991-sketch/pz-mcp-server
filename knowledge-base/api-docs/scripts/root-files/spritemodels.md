# ROOT-SpriteModels

Soft Override  
Unknown

Is Root  
True

Root patterns  
`media\/spriteModels\.txt$`

The `spriteModels.txt` file is used to register
[models](https://pz-wiki-modding.github.io/PZ-API-Docs/scripts/model.html)
and animations to tiles. This is notably used for radio items as well as
doors and ramps.

## Hierarchy

This block can have the following child blocks:

- [spriteModel](../spritemodel.md)

## ID

This block should have no ID.

## Parameters

This block has no parameters.
