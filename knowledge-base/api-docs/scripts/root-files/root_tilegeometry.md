# ROOT-TileGeometry

Soft Override  
Unknown

Is Root  
True

Root patterns  
`media\/tileGeometry\.txt$`

The `tileGeometry.txt` file is used to register the tile depth of tiles.
The file needs to be located inside the
[common/media](https://pzwiki.net/wiki/Mod_structure#Common_and_versioning_folders)
folder.

## Hierarchy

This block can have the following child blocks:

- [tileGeometry](../tilegeometry.md)

## ID

This block should have no ID.

## Parameters

This block has no parameters.
