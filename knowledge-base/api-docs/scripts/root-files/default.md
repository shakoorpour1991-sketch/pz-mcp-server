# ROOT-Default

Soft Override  
Unknown

Is Root  
True

Root patterns  
`mods/default\.txt$`

The default.txt file is used to select the mods and maps that will be
loaded by the game.

## Hierarchy

This block requires these following children to be valid:

- [mods](../mods.md)
- [maps](../maps.md)

## ID

This block should have no ID.

## Parameters

#### VERSION

Type  
integer

The version of the default.txt file. Keep it at 1.
