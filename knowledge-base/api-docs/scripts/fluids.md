# Fluids

Soft Override  
Unknown

Used to make a list of fluids to appear in a [FluidContainer
component](https://pz-wiki-modding.github.io/PZ-API-Docs/scripts/component/component_fluidcontainer.html).

## Hierarchy

This block can be a child of the following blocks:

- [component FluidContainer](./component/component-fluidcontainer.md)

## ID

This block should have no ID.

## Parameters

#### fluid

Type  
Unknown
