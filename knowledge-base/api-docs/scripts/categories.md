# Categories

Soft Override  
Unknown

Acts as a sort of tag list. Notably used in fluid scripts. Doesn't have
parameters and instead just functions as a list.

Available categories for fluids are:

- `Alcoholic`
- `Beverage`
- `Poisons`
- `Colors`
- `Medical`
- `Industrial`
- `Dyes`
- `HairDyes`
- `Paint`
- `Fuel`
- `Water`

Do note that some of these don't seem to do anything.

## Hierarchy

This block can be a child of the following blocks:

- [fluid](./fluid.md)
- [BlendWhiteList](./blendwhitelist.md)
- [BlendBlackList](./blendblacklist.md)

## ID

This block should have no ID.

## Parameters

This block has no parameters.
