# Root Files

Root files are the base files that contain the script block and their
parameters. Different script blocks go in different root files, which
are listed below. They are handled similarly to other script blocks to
them following similar behavior:

- children blocks
- parameters (in some cases)

They are your starting point for creating your own script blocks. The
pattern values are used as validators for a root file path and are
partial indicators of where the root file is located in the game or mod
files but the description will usually contain better detail about its
expected location.
