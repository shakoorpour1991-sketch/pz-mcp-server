# colors

Soft Override  
Unknown

Used to create a new color definition which can be then be used in other
blocks. Those colors are added to the available
[colors](https://pz-wiki-modding.github.io/PZ-API-Docs/java/colors.html)
via the use of
[Colors.AddGameColor](https://demiurgequantified.github.io/ProjectZomboidJavaDocs/zombie/core/Colors.html#AddGameColor(java.lang.String,zombie.core.Color)).

## Hierarchy

This block can be a child of the following blocks:

- [xuiSkin](./xuiskin.md)
